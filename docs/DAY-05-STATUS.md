# 5일차 — 관리자 계정 목록·관심 시장 저장

## 관리자

`/admin`에서 등록된 Event 프로필, 생성일, 상태, 역할, 만료되지 않은 Google 로그인 세션 수를 확인한다. 계정 화면에도 관리자 링크가 표시된다. 세션 수는 현재 온라인 여부를 뜻하지 않으며, 아직 Event 프로필을 만들지 않은 Google 로그인 사용자는 이 목록에 포함되지 않는다.

권한은 서버 환경 변수 `ADMIN_ACCOUNT_ID`와 인증된 Google subject로 조회한 앱 계정 ID의 정확한 일치, 그리고 active 상태로 판정한다. 이메일/표시 이름/브라우저 요청 값으로 권한을 부여하지 않는다. 관리자 지정은 사용자 스크린샷에 나온 계정 ID에만 적용했다. 일반 사용자의 관리자 페이지/API 접근은 차단한다. 현재 관리자 기능은 조회 전용이며 계정 정지나 다른 관리자 추가 기능은 제공하지 않는다.

## 관심 시장

북마크 추가/삭제는 D1 `watchlist_entries`에 계정별로 저장된다. 새로고침 및 재로그인 후 유지된다. 익명 사용자는 로그인/프로필 생성으로 안내한다. 중복 저장/삭제는 같은 결과를 반환하며, 저장 실패 시 성공한 것처럼 표시하지 않는다. 비활성화·정지 계정은 읽기와 변경을 거부한다. 비활성화는 관심 시장을 지우지 않으며, 재활성화 후 다시 사용할 수 있다.

현재 시장은 demo 공급자 상품이다. 실제 Kalshi 데이터는 아직 비활성화되어 있다. 다른 공급자를 연결하면 안정적인 공급자별 시장 ID와 만료/상장폐지 상품 표시 정책을 확장해야 한다.

## 보안과 검증

사용자별 SQL 범위와 FK/유일성 제약, 로그인 세션, 동일 출처 검사, 요청 스키마 검증을 적용한다. 관리자 응답에는 인증 토큰·Google subject·OAuth state·비밀키를 포함하지 않는다. 관리자 목록은 페이지당 50개이다. 사용자 간 관심 시장 분리, 같은 이메일을 가진 별도 subject 분리, 중복 요청, 정지/비활성화 계정, 관리자 접근 거부 및 세션 집계 테스트를 추가했다.

Google 로그인과 실제 프로필 저장은 사용자 화면에서 확인했다. 수수료는 이전과 같이 계약 금액의 0.25%, 주문별 센트 반올림이며 실제 주문/자금 이동은 없다.
