## 일정 운영

- 승인·계약 확보는 별도 업무 흐름이다. 위 일차에 상대방 승인이 난다고 가정하지 않는다.
- 26~29일 파트너 접근이 없으면 테스트 어댑터로 동일 시나리오를 검증하고 미검증 항목을 남긴다.
- 매일 시작할 때 현재 문서의 실제 진행 상황을 갱신한다. 자동 실행이나 예약은 설정하지 않았다.

## 1일차 실제 범위

완료: 샘플 시장 조회, 검색/카테고리, 세션 내 관심 시장, 상세 규칙, YES/NO 수량 입력, 서버 견적 계산, 검토 모달, 계정 연결 안내, 실거래 서버 차단, 계산/차단 테스트.
미구현: 사용자 인증, 영구 저장, 주문 접수/체결, 실제 시세, 은행 연결, 실제 수수료, KYC, 제휴 어댑터, 수익 수취.
관심 시장은 현재 페이지 메모리에만 유지된다. 표시되는 모든 시장·가격·차트는 fixture이며 제휴사의 상품이나 시세가 아니다.

모의 주문 접수·체결·예약 반환·매도 예약/해제의 내부 이벤트 수집과 처리 기록을 추가했다. 중복 방지, 처리 중단 후 재개, 과거 기록 복구와 계정별 거래 활동 화면을 지원한다. 한 요청에서 수집 100건·처리 50건으로 제한하며 화면의 동기화 버튼으로 이어서 처리한다. 상시 백그라운드 작업이나 금융 원장 재반영은 실행하지 않는다. `DAY-17.md` 참고.

### 18일차 완료
전체 모의 잔액·원장·주문 진행·체결·보유량·매도 예약을 같은 조회 시점에서 대조하는 화면을 추가했다. 16개 검사 항목, 전체 차이 집계, 최대 50건의 참조 번호와 기대값/기록값을 표시한다. 기존 수수료 정책도 보존하며 자동 잔액 수정이나 거래 재처리는 하지 않는다. `DAY-18.md` 참고.

### 19일차 로컬 구현 완료 — 배포 대기
관리자의 결과 판정안·근거 저장, 검토 후 YES/NO/VOID 확정, 마감 전 확정 및 확정 후 변경 차단, 변경 기록과 중복 요청 보호를 추가했다. 공개 이벤트의 최종 결과와 계정별 모의 정산 예상액을 표시하며 실제 지급·환불·보유량 소각은 실행하지 않는다. 자동 테스트 177개, 로컬 HTTP 검증과 배포용 빌드를 통과했다. 실행 정책으로 사이트 동기화 입력 전달이 차단되어 배포는 대기 중이다. `DAY-19.md` 참고.

### 20일차 로컬 구현 완료
전체 모의 거래 중지·재개, 사유·확인 창·변경 충돌/중복 방지, 관리자 감사 기록 조회·필터·페이지 이동을 추가했다. 중지 중 신규 매수·매도 예약·체결은 차단하며 기존 내역 조회·취소는 허용한다. 186개 자동 테스트, 타입 검사, 로컬 빌드와 HTTP 검증을 통과했다. 사용자 요청으로 배포는 시도하지 않았다. 로컬 Google 로그인은 미설정이므로 실제 관리자 로그인으로 직접 조작하는 검증은 아직 불가하다. `DAY-20.md` 참고.

### 21일차 로컬 구현 완료
`/practice/fees`에 계약당 0.25% 정책, 체결 수수료·원금·예약금·미사용 금액 반환을 구분한 내역과 전체 합계를 추가했다. 기존 체결 기록과 과거 반올림 정책을 유지하며 취소를 수수료 환불로 표시하지 않는다. 실제 수익·정산 환불은 발생하지 않는다. 자동 테스트 191개, 타입 검사, 로컬 HTTP와 빌드를 통과했다. 배포는 시도하지 않았다. `DAY-21.md` 참고.

### 22일차 로컬 구현 완료
앱 내 모의 거래 알림 목록, 읽음 처리·미확인 개수·페이지 이동, 계정별 알림 수집 켜기/끄기를 추가했다. 수동 동기화로 거래 기록을 최대 100건씩 수집하고 중복 알림을 방지한다. 꺼진 상태에서 수집한 기록은 재활성화해도 알리지 않으며 기존 알림은 유지한다. 이메일·푸시·상시 백그라운드 알림은 포함하지 않는다. 테스트 195개, 타입 검사, 빌드와 로컬 HTTP 검증을 통과했다. 로컬 로그인은 별도 설정이 필요하며 배포는 하지 않았다. `DAY-22.md` 참고.

### 23일차 로컬 구현 완료
본문 바로가기와 키보드 초점 표시, 모바일 버튼·입력란·줄바꿈, 확인 창 내부 스크롤, 동작 줄이기 설정을 반영했다. 알림·수수료의 로딩 안내와 페이지 이동 이름을 보완했다. 브라우저에서 320px 알림·수수료·계정 화면, 768px 포트폴리오의 가로 넘침 없음과 본문 초점 이동을 확인했다. 타입 검사와 빌드를 통과했으며 배포는 하지 않았다. 로그인 후 화면의 실제 사용자 검증과 전체 접근성 인증은 미완료다. `DAY-23.md` 참고.

### 24일차 로컬 구현 완료
주요 변경 API에 계정별 영구 요청 제한과 429/Retry-After 응답을 추가했다. 취소는 별도 한도로 분리하고 조회·로그아웃은 유지한다. 요청 본문을 스트림 단계에서 16KiB로 제한하고 JSON 형식을 정확히 검사하도록 보완했다. 테스트 200개, 타입 검사, 빌드와 로컬 HTTP 검증을 통과했다. 로그인·관리자 권한의 기존 방어를 검토했지만 비로그인 OAuth/조회 요청의 외곽 제한과 외부 보안 감사는 남아 있다. 배포는 하지 않았다. `DAY-24.md` 참고.
