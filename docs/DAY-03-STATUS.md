# 3일차 인계

## 완료

- Kalshi 공식 조회 문서 및 공개 이용 약관을 확인하고 기술적 접근과 상업적 이용 권한을 구분했다.
- 시장 목록/상세 조회 전용 서버 연결부를 추가했다. 고정 주소/GET, 페이지 이동, 시간 제한, 응답 검증과 명시적 오류를 지원한다.
- 소수점 4자리 달러 가격을 보존하며 조회 결과를 기존 샘플 견적으로 변환하지 않는다.
- 합성 데이터 기반 테스트 11개를 추가했다. 기존 33개와 합계 44개.
- 영문 제휴 제품 설명서와 권한·비용·수익화·계정 위임 질문서를 작성했다. 문의는 발송하지 않았다.
- 화면 개발 일차를 Day 03으로 갱신했다.

## 현재 상태

실제 API 호출·실제 시세·제휴 승인·입출금·거래 기능은 없다. 조회 연결부는 registry에 등록하지 않았다. 공개 API의 기술적 접근 가능성만으로 상업적 이용이나 제3자 거래 지원 권한을 가정하지 않는다. 기존 샘플 탐색/견적과 서버 주문 차단은 유지한다.

## 검증

전체 도메인/DB/조회 테스트, TypeScript 검사 및 배포 빌드를 수행한다. 합성 테스트는 실제 제공자 응답이나 상업적 사용 승인을 검증하지 않는다.

## 다음 작업

4일차: 앱 사용자 인증과 세션. 거래소 계정 인증과 앱 로그인을 구분한다. 파트너 승인이 없어도 앱 인증 구현은 진행 가능하다. 외부 계정 위임과 실거래는 승인된 연결 방식 확보 후 진행한다.
