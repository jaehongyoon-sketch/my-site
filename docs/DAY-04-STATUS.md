# 4일차 — Google 로그인·계정 관리·수수료

## 구현

- 앱 로그인은 Google 전용이다. ChatGPT 로그인 버튼, 계정 의존성, 앱 인증 helper를 제거했다. 호스팅 자체의 비공개 접근 정책은 변경하지 않았다.
- OAuth authorization code + PKCE S256, state와 브라우저 쿠키 연결, nonce 및 ID 토큰 서명/발급자/수신자/만료 검증.
- Google 토큰을 계속 저장하지 않는다. 7일 유효한 무작위 앱 세션을 발급하며 DB에는 세션 토큰의 SHA-256 해시만 저장한다. HTTPS에서는 HttpOnly/Secure/SameSite=Lax 쿠키를 사용한다.
- 신규 프로필 생성, 이름 수정, 새로고침 후 유지, 로그아웃, 계정 비활성화와 명시적 재활성화. 비활성화 시 이름을 지우고 모든 Google 앱 세션을 폐기한다. 계정 식별자/생성일은 유지한다.
- Google의 안정적인 subject를 계정 키로 사용한다. 이메일이 같다는 이유로 다른 계정을 병합하지 않는다. 이메일/비밀번호 변경과 Google 계정 복구는 Google에서 관리한다.
- 모든 계정 쓰기는 서버 인증 및 동일 출처 검사 후 실행한다. 요청 본문의 다른 사용자 ID는 거부한다. suspended 계정은 직접 복구할 수 없다.
- D1을 활성화하고 프로필·OAuth 흐름·세션 테이블을 추가했다. 기존 거래 관련 테이블은 아직 실제 거래 저장에 사용하지 않는다.

## Trading fee

앱 수수료 = contract cost × 0.25%. Contract cost는 계약 단가 × 수량이다. 주문별 최종 수수료를 가장 가까운 센트로 반올림하며 정확히 0.5센트는 올린다. 최소 수수료는 없다.

- $100.00 → $0.25, 합계 $100.25
- $1.99 → $0.00
- $2.00 → $0.01

클라이언트 미리보기와 서버 견적은 같은 정수 계산 함수를 사용한다. 제3자 거래소 수수료는 미확정이므로 합계는 '거래소 수수료 제외'로 표시한다. 실제 청구·주문은 비활성 상태다.

## 활성화 대기

Google OAuth Client ID와 Client Secret이 아직 제공되지 않아 실제 Google 계정 인증은 활성화하지 않았다. 설정이 없을 때 로그인 버튼은 비활성화되며 성공한 것처럼 표시하지 않는다. [Google 설정 안내](GOOGLE-LOGIN-SETUP.md)를 따라 설정해야 한다.

운영 Google 계정으로 동의 → 콜백 → 신규 프로필 → 재로그인하는 전체 흐름은 인증 정보 설정 후 별도 검증해야 한다. 로컬 테스트용으로 Google 로그인 성공을 위조하는 운영 경로나 환경 변수는 제공하지 않는다.

## 검증 범위

도메인/DB/계정 정책/Google 토큰·state·쿠키·세션/수수료 테스트, 타입 검사 및 Worker 빌드. 로컬 HTTP에서 미인증 차단, 프로필 저장, 출처 검사, 비활성화/재활성화, 로그아웃을 검증한다. 실제 Google 서버의 앱 승인·설정은 이 테스트가 검증하지 않는다.
